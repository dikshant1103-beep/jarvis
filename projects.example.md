# My software — copy this to projects.md

Jarvis folds this into its system prompt, so it can answer "how does X work"
or "what have I built". Keep each entry short — one block per project. The
value is having it know your stack and your paths, not having it recite prose.

## Live sites
- **Project name** (its-url.com) — one line on what it does. Stack. Anything
  unusual about how it deploys. Root: ~/path/to/it.

## Desktop / local apps
- **Project name** — what it does, in one line. The parts that matter
  technically. How it runs. Root: ~/path/to/it.

## Research / experiments
- **Project name** — the idea, the approach, and honestly where it stands
  (working, half-built, abandoned). Root: ~/path/to/it.

## Conventions
- Anything true across your projects: which Python you use where, a commit
  email you must use, a machine constraint, a directory you never touch.
